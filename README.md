# NL2 Blender Track Builder

A Blender add-on that rebuilds a NoLimits 2 roller coaster from your **own exported track spline and
supports**, so you can 3D-print a model of your ride.

The add-on:
- sweeps any of the game's track styles (41 styles, with their spine and rail variants) along the
  centre-of-rails spline you export from NoLimits 2;
- adds cross-ties, flanges and bolts at the spacing the game uses;
- builds the support structure from the exported supports XML. That includes steel columns and braces,
  footers, track connectors, RMC-style wooden bents, catwalks, handrails and cables.

Because the model is generated from your own layout data rather than ripped from the game, this is the route
to use if you want a model you can sell (see the next section). With **Procedural Parts Only** (the default
when no game asset pack is installed), every part of the model is original geometry made by the add-on.

Its companion project, [nl2-model-export](https://github.com/zm2283145/nl2-model-export), rips the rendered
models straight out of the game. That route is more exact, but it is **personal use only**.

## ⚠️ What you may sell, and what you may not

**Models built from your spline export with *Procedural Parts Only* can be sold, if you choose to.**

- With **Procedural Parts Only**, everything is generated by this add-on's own code from **your** layout data:
  - rails, spines and box/tube sections;
  - cross-ties, flanges and bolts;
  - support columns, braces, wooden bents, catwalks and handrails;
  - track connectors and footers.

  No game meshes are used, so those parts are yours. The build info and the panel show
  *"procedural parts only - original model, OK to sell"*.
- ⚠️ **Game asset pack builds are personal use only.** If you have built the optional asset pack from your
  own NoLimits 2 install (see *Game asset pack* below) and turn *Procedural Parts Only* off, some parts are
  copied from the game:
  - cross-ties, and the flange/joint ties on styles that have them;
  - track connectors;
  - footers;
  - optionally, bolts.

  Those meshes belong to the NoLimits 2 developers. **A model that includes them must not be sold or
  redistributed.** The panel then shows *"includes game parts - personal use only"*.
- Models ripped with the DLL from [nl2-model-export](https://github.com/zm2283145/nl2-model-export) **must
  never be sold**. They are the game's own models.
- Manufacturer and ride names (B&M, Intamin, Arrow, RMC, Vekoma and others, or a specific park's ride) are
  trademarks of their owners. They are used here only to describe the track styles. Don't market prints as
  official products of those companies or parks.

This project is not affiliated with or endorsed by the makers of NoLimits 2. NoLimits is a trademark of its
owners. This section is guidance, not legal advice. If you plan to sell, check the rules that apply to you.

## Install

1. Download `nl2_track_builder.zip` from the releases. It contains no game assets and works as-is, building
   fully procedural (sellable) models.
2. In Blender 4.2 or later, open **Edit → Preferences → Add-ons**, choose **Install from Disk…**, select the
   zip, and enable **NL2 Track Builder**.
3. The panel is in the 3D Viewport sidebar (press **N**) on the **NL2** tab. The version is shown at the top.

## Export your ride from NoLimits 2

In the NoLimits 2 editor, export:

1. **The track spline as CSV**, using the **centre of rails**, with points about **0.5 m** apart.
2. **The supports as XML.**

Only the track that is in the CSV gets supports attached. Supports that belong to other tracks in the park
(for example a transfer or storage track) are skipped and counted in the build info.

## Build

1. Pick the spline CSV and the supports XML.
2. Choose the track style and its spine/rail option.
3. Click **Build Track + Supports**, or build the track or supports on their own.

| Option | What it does |
|---|---|
| Procedural Parts Only | Build every part with original geometry (sellable). Always on without an asset pack |
| Inverted / Close | Flip the track; close the circuit (Auto detects it) |
| Tie Spacing, Flange Interval, Gauge, Rail Radius | Override the style defaults (0 = default) |
| Support Attach Offset | Where supports meet the track (0 = style default) |
| Support Track Index | Which track's supports belong to this spline (−1 = auto) |
| Tube Sides | Roundness of the tubes |
| Ties / Flanges / Bolts / Footers / Track Connectors | Turn parts on or off |
| Realize Bolts | Turn instanced bolts into real geometry, which you need for export and printing |
| Colours | Rail, tie, spine, accent, support, concrete, bolt and metal colours, plus spine colour modes |

For printing, check **Realize Bolts** (or turn bolts off), scale the model, and use Blender's
**3D Print Toolbox** to check wall thickness and manifold geometry.

## Game asset pack (optional, personal use only)

You don't need this. It only swaps the procedural ties, connectors and footers for the game's exact models,
which makes a closer replica **for personal use only**. With the pack installed, the add-on can use these
meshes from **your own** NoLimits 2 install:
- the exact cross-tie models;
- the track connectors;
- the footers.

They are not in this repository, and must never be committed or shared.

To build the pack:

1. Write the list of files the add-on needs:
   ```bat
   python build_assets.py --list nl2vfsdump.txt
   ```
2. Dump those files from the game with `nl2vfsdump.dll` from
   [nl2-model-export](https://github.com/zm2283145/nl2-model-export). Put `nl2vfsdump.txt` next to the DLL,
   start the game, and inject it with `nl2inject.exe nl2vfsdump.dll`. The files land in `vfs\data\` next to
   the DLL.
3. Build the pack into the add-on folder:
   ```bat
   python build_assets.py --vfs <path to>\vfs\data
   ```
   Without `--bolts`, simple procedural bolts and nuts are generated.
4. Package and install:
   ```bat
   python make_package.py
   ```
   This bumps the version, builds `nl2_track_builder.zip` and installs it into Blender's user extensions
   folder. Restart Blender afterwards.

For anything you share, build the zip with `python make_package.py --public`, which leaves the asset pack out.

## Development

| File | Purpose |
|---|---|
| `nl2_track_builder/core.py` | Geometry: spline frames, sweeps, ties, flanges, supports XML parser and builder (numpy only, no `bpy`) |
| `nl2_track_builder/procedural.py` | Original ties, clamps, connectors, footers and bolts used by *Procedural Parts Only* |
| `nl2_track_builder/styles.py` | Track style definitions: gauge, rail radius, spine sections, tie and connector models |
| `nl2_track_builder/ui.py`, `blender_build.py` | Blender panel, operators, materials and instancing |
| `build_assets.py`, `lwo.py`, `tds.py` | Build the personal asset pack from a game-file dump (LightWave / 3DS readers) |
| `make_package.py` | Version bump (`--minor` for a feature release), zip and local install |
